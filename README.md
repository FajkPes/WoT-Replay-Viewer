# WoT Replay Viewer

A local viewer for exploring information and results stored in World of Tanks replay files.

## What it does

WoT Replay Viewer reads the information and result data available in a World of Tanks replay and presents it in a local browser page. It is useful for inspecting a replay without sending it to an online service.

## Use it

1. Download the ZIP from [Releases](https://github.com/FajkPes/WoT-Replay-Viewer/releases/latest) and extract it.
2. Open `replay-viewer.html` in a current browser.
3. Select a `.wotreplay` file and inspect the available battle details and results.

Everything is processed locally. The information available depends on the replay and game version. The page does not replay the battle in 3D or reconstruct vehicle movement. The current interface is in Czech.
